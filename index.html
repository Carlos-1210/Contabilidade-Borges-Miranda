Configuração de Conexão


                

                    
 Onde configurar

                    
Existe apenas UM lugar no arquivo .html para mexer: role até o final do arquivo (antes de </body>) e procure o bloco escrito "COLOQUE AQUI SEUS DADOS DO SUPABASE". O SQL para criar a tabela também está ali, como comentário, pronto para copiar.

                    
Status atual: verificando...

                


                

                    
 Ativar login por e-mail no Supabase

                    
No painel do Supabase: Authentication → Providers, confirme que "Email" está habilitado. Para testar sem confirmar e-mail toda vez, vá em Authentication → Settings e desative "Confirm email" (religue antes de usar com usuários reais).
